# Ses yuvaları

`manifest.json` içindeki dosya adlarıyla bu klasöre koy:

| Yuva | Dosya | İçerik |
|---|---|---|
| Müzik | `music_kahvehane.m4a` | Hafif, döngüsel, akustik bir parça (bağlama ya da ud esintisi) |
| Ortam | `amb_kahvehane_ugultu.m4a` | Kahvehane uğultusu (döngüsel) |
| Tek seferlik | `amb_tavla_zar.m4a` | Tavla zarı sesi |
| Tek seferlik | `amb_caycii.m4a` | Uzaktan gelen "Çaycııı!" |

Dosya yoksa oyun sessizce geçer. Efektler (damla, şeker, kaşık…) ZzFX ile prosedüreldir; döküm sesi `pourSynth.ts` ile üretilir.
